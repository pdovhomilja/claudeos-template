# System improvements ledger

Proposals for improving {{ASSISTANT_NAME}}'s own system (twin, scripts, timers, mail flow). Each night run looks back over the last 24 h, writes at most 3 new proposals to `wiki/twin/YYYY-MM/<date>-improve.md`, and `run.sh` posts them to Discord. {{USER_NAME}} replies "ok 1,3" / "no 2"; the next run sets the status here. Accepted ones are built in an interactive session.

Status: `open` → `accepted` / `rejected` → `done`. Never re-propose a rejected idea without new evidence.
